# festival

인력 에이전시(행사 스태프) 통합 관리 시스템의 관리자 프론트엔드 프로토타입.
서버는 아직 없고 MSW 목업이 전체 API를 대신하므로, 브라우저만 있으면 그대로 돌아간다.

- 데모: https://tmdi8635.github.io/festival/
- 규칙과 구조는 [CLAUDE.md](CLAUDE.md)와 `docs/`를 본다.

```bash
npm install
npm run dev
```

`main`에 밀면 깃허브 페이지로 자동 배포된다. (`.github/workflows/deploy-pages.yml`)
